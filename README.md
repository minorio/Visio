# Visio — See Beyond the Screen 🎬

**Visio** — A cinematic ecosystem for those who value the art of moving images. Сurate your personal film library with a seamless interface.

## 🚀 Features

- **Trending Now:** Real-time popular movies via TMDB API.
- **Deep Insights:** Detailed info, ratings, and cast for every film.
- **Personal Vault:** Manage your favorites and liked movies.
- **Smart Search:** Debounced live search with filters.

## 🛠 Tech Stack

- **Framework:** Angular 18 (Standalone Components)
- **State Management:** NgRx (Store, Effects, Entity)
- **Reactive Programming:** RxJS
- **UI Library:** Angular Material & SCSS
- **Data Source:** The Movie Database (TMDB) API

## 🏗 Development Setup

### Prerequisites

- Node.js (v18+)
- Angular CLI (`npm install -g @angular/cli`)

### Installation

1. Clone the repository: `git clone <repo-url>`
2. Install dependencies: `npm install`
3. Set up your API key in `src/environments/environment.ts` (see `.env.example`)
4. Run the server: `ng serve`

Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.
